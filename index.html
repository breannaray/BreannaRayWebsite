Project Description

This web application was developed by Breanna Ray as part of a quantitative finance coursework requirement. It leverages modern web technologies (HTML5, Tailwind CSS, and JavaScript with Chart.js) to build a fully functional, responsive financial calculator website.

Core Methodologies & Calculations

  • Holding-Period Return (HPR): Measures total return including price appreciation over the selected time horizon.
  • Annualized Return (CAGR): Converts multi-year or fractional-year returns into an annualized compound rate.
  • Sharpe Ratio: Evaluates excess returns per unit of total risk (standard deviation) relative to the risk-free rate.
  • Systematic Risk & Valuation: Computes asset betas relative to market benchmarks alongside fundamental valuation metrics (P/E, Dividend Yield, and Market Capitalization).
